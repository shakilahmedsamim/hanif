# How to add your own images

Upload your image files into this folder (`public/images/`) directly on
GitHub — no coding needed:

1. Open this folder on GitHub: `public/images/`
2. Click **Add file → Upload files**
3. Drag your image in, **rename it to match one of the exact filenames
   below**, then commit

The site checks for these exact filenames. Some are already wired up —
upload with that name and it appears automatically, no further changes
needed. For anything else, upload with any clear descriptive name and
tell Claude the filename in chat so it can be wired into the right page.

## Already wired — just upload with this exact name

| Filename | Used on | Recommended size |
| --- | --- | --- |
| `about-founder.jpg` | About page, founder photo | 800x800px (square) |

## Not wired yet — upload, then tell Claude the filename

- Case study before/after screenshots (e.g. `case-study-hvac-before.png`,
  `case-study-hvac-after.png`) — recommended 1200x750px
- Real client/partner logos
- A current Google Partner badge image
- Anything else you want added to the site

Keep filenames lowercase with hyphens (no spaces), and keep images
reasonably sized (compressed JPG/PNG/WebP) so the site stays fast.
